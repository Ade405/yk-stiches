# YK Stitches — Cookies Notice

**Status:** Draft template for deployment review  
**Last updated:** 22 October 2026

## Essential cookies
The server uses session cookies for authentication. The current server configuration sets cookies to HttpOnly and SameSite=Lax and enables Secure in production. These cookies support sign-in, session continuity, and account security.

## Browser storage and third-party technologies
The exact browser storage and network requests depend on the deployed frontend and enabled integrations. Before launch, inspect production traffic and code for local storage, embedded content, analytics, advertising pixels, and other third-party tags, then list each technology, purpose, provider, and expiry here.

## Optional analytics or marketing
This repository does not, by itself, establish that non-essential analytics or advertising cookies are deployed. If such tools are added, update this notice and implement any consent or preference controls required by applicable law before enabling them.

## Managing cookies
Browser settings can block or delete cookies. Blocking essential session cookies may prevent sign-in or other account features from working.
